# QuickBite – Food Ordering Prototype

QuickBite is a food ordering prototype focused on transparent pricing and a simple checkout experience.

## Features
- Add or remove food quantities
- Apply the `WELCOME10` promo code
- View subtotal, delivery fee, tax, discount, and final total
- Review delivery details
- Select a payment method
- View order confirmation

## Technologies
- HTML
- CSS
- JavaScript

## How to Run
1. Download or clone this repository.
2. Open `index.html` in a browser.

## Note
This is a demonstration prototype. It does not process real payments or submit actual food orders.
